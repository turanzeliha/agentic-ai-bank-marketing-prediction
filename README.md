# Agentic AI-Powered Predictive Analytics
## Overview
A multi-agent predictive analytics project that predicts bank term deposit subscriptions and translates machine learning outputs into actionable business insights.
## Project Architecture
- **Preprocessing Agent:** Data preprocessing and feature engineering.
- **Modeling Agent:** Random Forest, GridSearchCV and model evaluation.
- **Insight Agent:** LLM-powered interpretation of predictions and business recommendations.
## Technologies
Python, scikit-learn, Pandas, LangGraph, LangChain and LLM integration.
## Model Performance
| Metric | Score |
|---|---:|
| ROC-AUC | 0.8018 |
| F1-score | 0.4731 |
| Precision | 0.4188 |
| Recall | 0.5435 |
## Dataset
UCI Machine Learning Repository — Bank Marketing dataset.
## Objective
To connect predictive modeling with agent-based AI workflows and generate practical business insights.
